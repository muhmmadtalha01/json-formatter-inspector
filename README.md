# MT JSON Formatter & Inspector

A fast, secure, and offline JSON formatter with lossless number precision, built for Microsoft Edge and Chrome.

## Features
- **Lossless Numbers:** Prevents large integer corruption.
- **Interactive Tree View:** Collapse and expand nested JSON.
- **Click-to-Copy Path:** Quickly get JSON Paths (e.g., `$.data.id`).
- **Dark & Light Mode:** Beautiful UI with saved preferences.
- **100% Offline:** No data is ever sent to any server.

## Privacy Policy
This extension does not collect, store, or transmit any personal data or JSON content. All processing is done locally on your device. The only external connection is made via a secure Cloudflare Worker to verify Payhip license keys for the Pro version.
